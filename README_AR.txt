ملفات تشغيل بوت تيليجرام على Railway

المحتويات:
- main.py: ملف تشغيل البوت.
- requirements.txt: المكتبات المطلوبة.
- Procfile و railway.json: إعدادات بدء التشغيل على Railway.

طريقة الرفع:
1) ارفع كل الملفات إلى مستودع GitHub خاص (Private).
2) في Railway اختر New Project ثم Deploy from GitHub Repo.
3) اختر المستودع.
4) افتح Variables وأضف:
   TELEGRAM_BOT_TOKEN = توكن جديد من BotFather
5) أمر التشغيل هو: python main.py

مهم:
- لا تضع التوكن داخل GitHub ولا ترسله في المحادثات.
- التوكن الذي سبق إرساله يجب إلغاؤه من BotFather وإصدار توكن جديد.
- هذه النسخة الآمنة تستقبل الملفات وتحفظها، لكنها لا تنفذ ملفات Python المرفوعة من المستخدمين.
- Railway قد يحذف الملفات المحلية عند إعادة النشر أو تغيير الحاوية؛ استخدم قاعدة بيانات/تخزين دائم عند الحاجة.
